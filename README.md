# Prototipos CECyT 5 (SSTIE)

El **Concurso: Premio a los Mejores Prototipos del Nivel Medio Superior** es un evento anual que organiza el Instituto Politécnico Nacional (IPN) a nivel de media superior con el objetivo de impulsar la creatividad, innovación y el talento de las y los estudiantes de los CECyT.

Dentro de los prototipos, existen diferentes categorías: Desarrollo de Software, Soluciones Domésticas, Maquinaria y Equipo Productivo, Productos para la Salud, Productos para la Enseñanza, Procesos Químico y Aplicación para la Empresa.

Como prototipo, nuestro equipo presenta la aplicación móvil de **SSTIE** (Sitema de Soporte Técnico de Informática Escolarizada). Esta aplicación tendrá como principal objetivo **agilizar el reporte de fallos técnicos en los equipos de cómputo dentro de las aulas escolares del CECyT 5** "Benito Juárez".

El proyecto será manejado mediante el uso de diversas tecnologías como lo son:

- Android Studio
- Visual Studio Code
- Node.js
- Express.js
- Git
- GitHub
- Render
- MongoDB

Y como lenguajes para el desarrollo del proyecto, tenemos:

- Kotlin
- HTML
- CSS
- JavaScript
- TypeScript
